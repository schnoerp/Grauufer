# Dungeons aus dem Dungeon-Baukasten

Hier liegen die Dungeons, die ins Spiel kommen: je Dungeon eine JSON-Datei aus dem Dungeon-Baukasten (`werkstatt/dungeonbaukasten.html`, „Herunterladen“ oder über GitHub an Claudia gesendet).
Der Dateiname (ohne `.json`) ist die feste Kennung des Dungeons im Spiel und sollte sich nicht mehr ändern.

`npm run dungeons` bettet alle Dateien in `index.html` ein (zwischen `/*#DUNGEONS*/` und `/*#DUNGEONS-ENDE*/`).
